# قائمة مخبز صاروج بيكري الإلكترونية

موقع بسيط بلغة HTML لعرض قائمة المنتجات، بدون سيرفر أو قاعدة بيانات — يعمل مباشرة من GitHub Pages.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة التي يشوفها الزبون: يتصفح المنتجات، يختار ما يريد، ثم يعرضها على الجرسون. لا يوجد فيها أي عملية شراء أو دفع. |
| `admin.html` | صفحة تساعدك تعدّل الأسماء والأسعار وتوفر المنتجات بشكل مرئي، ثم "تصدّر" لك كود جاهز تلصقه في `data.js`. |
| `data.js` | ملف بيانات المنتجات والأسعار نفسه. هذا هو الملف الوحيد اللي تحتاج تعدله فعليًا لحفظ التغييرات. |

## كيف يشتغل الاختيار وعرضه على الجرسون

1. الزبون يفتح `index.html` (من رابط أو QR code على الطاولة).
2. يتصفح الأقسام (شاي، قهوة، حلويات...) ويضغط "+" على أي منتج يعجبه.
3. يظهر شريط أسفل الشاشة يعرض عدد الأصناف المختارة.
4. يضغط "عرض على الجرسون" فتظهر شاشة كبيرة وواضحة (تصميم يشبه تذكرة الطلب) فيها كل الأصناف والكميات والسعر الإجمالي.
5. الجرسون يشوف هذه الشاشة من جوال الزبون ويسجل الطلب يدويًا — لا يوجد إرسال إلكتروني ولا دفع.

## طريقة تعديل الأسعار أو المنتجات (الأسهل)

1. افتح `admin.html` في المتصفح (تقدر تفتحه من جهازك مباشرة بالنقر المزدوج على الملف).
2. عدّل الأسماء / الأسعار / علّم "متوفر" أو ألغِها / أضف أو احذف منتجات وأقسام.
3. اضغط **"تصدير الكود المحدث"** بالأسفل، ثم **"نسخ النص"**.
4. افتح ملف `data.js` بأي محرر نصوص (مثل Notepad أو VS Code)، احذف كل المحتوى، والصق النص المنسوخ، ثم احفظ.
5. افتح **GitHub Desktop**:
   - بيظهر لك التغيير على ملف `data.js`.
   - اكتب وصف بسيط في خانة **Summary** (مثال: "تحديث سعر القهوة العمانية").
   - اضغط **Commit to main**.
   - اضغط **Push origin**.
6. خلال دقيقة أو دقيقتين تنعكس التغييرات على الموقع المباشر تلقائيًا (إذا كان GitHub Pages مفعّل).

> ملاحظة: التعديل يدوي بالكامل حسب رغبتك — لا يوجد حفظ تلقائي على الإنترنت من صفحة الإدارة نفسها.

## نشر الموقع عبر GitHub Pages (مرة واحدة فقط)

1. ادخل على مستودعك `github.com/maawali-s/sarouj-bakery`.
2. اذهب إلى **Settings → Pages**.
3. تحت **Source** اختر **Deploy from a branch**، وفرع **main**، ومجلد **/ (root)** — أو إذا وضعت هذه الملفات داخل مجلد فرعي مثل `menu/` اختره من هناك.
4. احفظ. سيعطيك GitHub رابطًا مثل:
   `https://maawali-s.github.io/sarouj-bakery/index.html`
5. هذا هو الرابط اللي تحوّله إلى QR code وتحطه على الطاولات.

## توليد QR Code للرابط

بعد ما يصير عندك الرابط النهائي، تقدر تسوي له QR code مجانًا من أي موقع مثل qr-code-generator.com، أو أطلب مني أصممه لك بمجرد ما يجهز الرابط.

## أين أضع هذه الملفات؟

عندك خياران:
- **بمشروع منفصل تمامًا** عن مشروع Next.js الحالي (مستودع GitHub جديد أو مجلد فرعي جديد بنفس المستودع مثل `/menu`).
- الأفضل: مستودع جديد بسيط خاص بهذه القائمة، لأنه لا علاقة تقنية له بمشروع Next.js/Prisma/Docker — هذا حل بسيط ومستقل تمامًا.
